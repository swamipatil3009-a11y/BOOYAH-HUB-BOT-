# BOOYAH HUB Discord Bot

Daily Free Fire scrim registration bot.

- Scrim: 9:00 PM IST
- Registration: 6:00 PM IST
- 12 slots
- Captain + 3 main players
- 1 substitute
- Automatic slot assignment
- SQLite storage
- `/setup` creates the registration panel
- `/slots` posts the current slot list

## Environment variables
Copy `.env.example` to `.env` and fill in your own values. Never share `.env` or your bot token.

## Run
```bash
npm install
npm start
```
